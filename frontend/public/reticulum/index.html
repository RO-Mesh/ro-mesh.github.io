Reticulum — Stivă de rețea cu criptografie end-to-end implicită, ce conectează LoRa, Wi-Fi și internet într-un singur strat de comunicație resilient.

Proiectat pentru scenarii în care confidențialitatea și reziliența infrastructurii contează mai mult decât simplitatea de configurare. Fiecare pachet este criptat matematic înainte de a părăsi nodul — fără setări suplimentare.

Cele 3 metrici esențiale

Dificultate instalare

Ridicată

Necesită Linux (Raspberry Pi sau echivalent), instalare prin pip/Python, configurarea manuală a fișierului config și cunoașterea conceptelor de interfețe de rețea. Nu există Web Flasher.

Complexitate configurare

Ridicată

Configurarea interfețelor (LoRa + Wi-Fi + TCP), setarea bridge-urilor și alegerea aplicației client (Nomad Network, Sideband) necesită experiență solidă în rețelistică și Linux.

Disponibilitate rețea

Scăzută

Comunitate mică în România. Fiecare utilizator trebuie să construiască propria infrastructură — nu există noduri publice preexistente de care să te conectezi imediat.

Avantaje

  • Criptografie end-to-end implicită — nu este nevoie să activezi manual securitatea.
  • Agnostic de mediu — rulează pe LoRa, Wi-Fi, Ethernet, fibră sau TCP/IP simultan.
  • Arhitectură P2P reală, fără punct central de eșec sau server de înregistrare.
  • Suportă transfer de fișiere mari și mesagerie asincronă prin LXMF.

Dezavantaje

  • Curbă de învățare semnificativă — necesită cunoștințe Linux și rețelistică.
  • Nu există interfață grafică nativă simplă pentru configurare hardware.
  • Comunitate mult mai mică în România față de Meshtastic.
  • Incompatibil direct cu MeshCore sau Meshtastic (fără bridge dedicat).
Concluzie: Reticulum este alegerea potrivită dacă ai experiență Linux, înțelegi concepte de rețelistică și ai nevoie de o stivă completă pentru un scenariu tactic complex — bridging LoRa cu internet, transfer securizat de fișiere sau o rețea de noduri complet independentă de orice infrastructură comercială.

Echipamente

Hardware recomandat

Spre deosebire de MeshCore și Meshtastic, Reticulum rulează pe un calculator complet (Linux) și comunică prin interfețe hardware LoRa conectate prin USB sau SPI. Există două configurații principale.

🖥 Nod fix — Raspberry Pi + HAT LoRa

Configurație nod gateway

Raspberry Pi Zero 2W / Pi 4 + RNode HAT

Combinația standard recomandată de comunitatea Reticulum este un Raspberry Pi Zero 2W cu un modul LoRa SX1262 conectat pe SPI sau un RNode (dispozitiv dedicat dezvoltat de comunitate) conectat prin USB. RNode este recomandat pentru simplitate — se configurează ca interfață serială standard, fără driver special.

Pi Zero 2W consumă ~0.9–1.5 W în repaus, suficient pentru alimentare solară cu un panou de 5 W și o baterie de 5000 mAh — autonomie completă pe durata nopții.

📱 Nod portabil — Android + Sideband

Nod mobil prin Bluetooth/USB

Orice telefon Android + RNode / T-Echo (firmware RNode)

Aplicația Sideband (disponibilă pe Android) permite utilizarea Reticulum direct de pe telefon, conectat la un RNode prin Bluetooth sau USB-OTG. Această configurație este cea mai accesibilă cale de testare a protocolului fără un Raspberry Pi dedicat.

LILYGO T-Echo flashat cu firmware RNode poate funcționa ca interfață LoRa pentru Sideband — transformând un telefon Android într-un nod Reticulum portabil, inclusiv cu GPS și ecran e-ink.

Notă de complexitate: Configurarea unui nod Reticulum funcțional necesită editarea manuală a fișierului ~/.reticulum/config și familiarizarea cu conceptele de transport, interfețe și destinații. Consultați reticulum.network/manual înainte de a comanda hardware.

Strategie PARU

Când alegi Reticulum în strategia PARU?

Reticulum nu este un layer de comunicație simplu — este o stivă de rețea completă. Din perspectiva PARU, funcționează optim ca layer de Rezervă sau Urgență pentru scenarii care necesită securitate criptografică dovedită și bridging de medii diferite. Nu este recomandat ca primă alegere pentru utilizatorii fără experiență Linux.

Comunicare primară

Telefon mobil, internet, aplicații standard. Reticulum nu este adecvat pentru utilizare zilnică curentă.

Aplicabil dacă infrastructura există

Dacă ai deja noduri Reticulum configurate și funcționale, poate prelua comunicarea când rețeaua mobilă cedează. Necesită planificare avansată.

Ghid rapid

Instalare în patru pași

  1. Pasul 01

    Pregătește hardware-ul și sistemul de operare

    Instalează Raspberry Pi OS Lite pe un Pi Zero 2W sau Pi 4. Conectează modulul LoRa (RNode prin USB sau HAT SX1262 pe SPI). Asigură-te că Python 3.7+ este disponibil — vine preinstalat pe Pi OS.

  2. Pasul 02

    Instalează Reticulum prin pip

    Rulează în terminal:

    pip install rns

    Prima pornire generează automat fișierul de configurare în ~/.reticulum/config. Editează secțiunea [[RNodeInterface]] cu portul serial al modului LoRa și frecvența de 868 MHz.

  3. Pasul 03

    Instalează o aplicație client

    Nomad Network — interfață terminal pentru mesagerie și pagini (rulează pe Pi direct):

    pip install nomadnet && nomadnet

    Alternativ, Sideband pe Android (conectat la Pi prin SSH sau la un RNode prin USB-OTG) oferă o interfață grafică accesibilă pentru mesagerie și transfer de fișiere.

  4. Pasul 04

    Verifici conectivitatea și trimiți primul mesaj

    Rulează rnstatus pentru a verifica că interfețele sunt active. Dacă există un al doilea nod Reticulum în raza LoRa, se va anunța automat prin protocol de anunț. Trimiți primul mesaj prin Nomad Network sau Sideband — complet criptat, fără server intermediar.
